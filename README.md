# UCS301 - Data Structures

## Lab Assignment 1

**Week 1**

This repository contains the C++ programs implemented for UCS301 Data Structures Lab Assignment 1.

---

## 📚 Assignment Questions

### Q1. Menu-Driven Array Operations

A menu-driven program demonstrating the following array operations:

- Create
- Display
- Insert
- Delete
- Linear Search
- Exit

**File:** `Q1_Array_Menu_Driven.cpp`

---

### Q2. Remove Duplicate Elements

A program to remove duplicate elements from an array so that the resulting array contains only unique elements.

**File:** `Q2_Remove_Duplicates.cpp`

---

### Q3. Array Rotation by K Positions

A program to rotate a one-dimensional array by `K` positions in both directions:

- Left Rotation
- Right Rotation

**File:** `Q3_Array_Rotation.cpp`

---

### Q4. Array and Matrix Operations

This program implements:

1. Reverse the elements of an array
2. Matrix multiplication
3. Matrix transpose

**File:** `Q4_Array_Matrix_Operations.cpp`

---

### Q5. Row and Column Sum

A program to calculate the sum of every row and every column of a two-dimensional array.

**File:** `Q5_Row_Column_Sum.cpp`
